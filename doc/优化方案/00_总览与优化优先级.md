## Aigen 的独特价值定位

在整个 z-biz-tool 系列中，aigen 是唯一以"多模态内容生成"为核心的应用：把 **图片 / 视频 / PPT / 文本** 四类生成能力聚合到一个 Tauri 桌面壳内，通过统一的 `baseUrl + apiKey`（OpenAI 兼容格式）对接外部模型服务。其独特点：

1. **一站式多模态**：单窗口左侧菜单切换四类生成面板（[`src/App.tsx`](../../src/App.tsx) 第 56-61、91-94 行），共享同一套 API 配置与生成骨架 [`useGeneration`](../../src/_shared/useGeneration.ts)。
2. **Rust 侧统一网关**：所有外部 AI 调用集中在 [`src-tauri/src/ai_client.rs`](../../src-tauri/src/ai_client.rs)，前端只经 Tauri command 触达，天然具备"密钥不下发到浏览器 fetch"的架构潜力（但当前实现未兑现，见 01/04）。
3. **PPT 生成落地为本地 HTML**：[`generate_ppt_file`](../../src-tauri/src/ai_client.rs)（第 256-322 行）是四类能力中唯一真正产出本地文件产物者，具备"生成即可交付"的雏形。

> 独特价值不等于已完善：视频/PPT 在 [`README.md`](../../README.md) 第 8-9 行被明确标注为"UI 框架，功能开发中"，`src/agent/` 目录则是与本项目无关的 SQL Agent 残留代码（详见 01 文档 A1）。优化的目标是把"多模态生成"从原型推进到可靠、可控、可信赖的桌面产品。

## 立即处理（P0）—— 安全与正确性红线

以下四项属于"密钥不泄漏、生成可取消、失败可降级、Agent 不自动执行破坏操作"核心原则的直接违背或严重风险，应最优先：

- **P0-1 密钥明文落盘且回传前端**：`api_key` 以明文写入 `~/.z-biz-tool-aigen/config.json`（[`ai_client.rs`](../../src-tauri/src/ai_client.rs) 第 57-64 行），并经 `load_api_config` 全量返回前端、存入 Zustand 与 React state（[`aiStore.ts`](../../src/stores/aiStore.ts) 第 46-58 行、[`App.tsx`](../../src/App.tsx) 第 27/32/42 行）。同时 CSP 为 `null`（[`tauri.conf.json`](../../src-tauri/tauri.conf.json) 第 23 行）。→ 详见 04。
- **P0-2 生成不可取消、无超时**：所有请求用 `Client::new()`（无 timeout，[`ai_client.rs`](../../src-tauri/src/ai_client.rs) 第 85/139/189 行），前端 `useGeneration` 无 abort/cancel（[`useGeneration.ts`](../../src/_shared/useGeneration.ts) 第 17-28 行）。长任务会无限挂起且无法中止。
- **P0-3 图片 model/size 参数被静默丢弃**：前端传 `model`、`size`（[`ImageGenPanel.tsx`](../../src/components/ImageGenPanel.tsx) 第 46 行），但后端 command 只接收 `prompt`/`count`（[`commands.rs`](../../src-tauri/src/commands.rs) 第 6-10 行），`generate_image_api` 硬编码 `size:"1024x1024"` 且不带 model（[`ai_client.rs`](../../src-tauri/src/ai_client.rs) 第 87-91 行）。用户选择完全无效——功能性正确性缺陷。
- **P0-4 失败无降级、错误裸传**：`useGeneration` 用 `String(e)` 直接把后端错误串（可能含 API 响应体）显示给用户（[`useGeneration.ts`](../../src/_shared/useGeneration.ts) 第 23-24 行），无错误分类、无重试、无降级路径。

## 核心原则（贯穿全套方案）

1. **密钥不泄漏**：不出现在日志、错误消息、前端可读内存明文、构建产物中。
2. **生成可取消**：任何长任务都能被用户中止，后端及时释放连接。
3. **失败可降级**：网络/额度/解析失败有明确的用户可理解反馈与备选路径。
4. **Agent 不自动执行破坏操作**：任何自动化仅产出建议，落盘/删除/覆盖须用户显式确认。
