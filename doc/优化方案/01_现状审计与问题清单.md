## 2. 【已确认缺陷】

### A 类：安全与隐私
- **A1 `src/agent/` 为无关的 SQL Agent 死代码**：[`src/agent/AgentManager.ts`](../../src/agent/AgentManager.ts) 自称 `name:'SQL Agent'`（第 19 行），`query/optimize/analyze/diagnoseError` 全部是 `// TODO: 调用 Agent 服务` 后返回硬编码假数据（第 40-46、77-83、114-120、151-157 行）；[`types.ts`](../../src/agent/types.ts) 围绕 `connectionId/databaseType/tables`。App.tsx 与四面板均未 import 该模块（Grep 仅在 agent 目录内自引用）。→ 与 AI 生成无关的残留，增加维护面与误解风险。
- **A2 API Key 明文落盘**：[`save_config`](../../src-tauri/src/ai_client.rs) 用 `serde_json::to_string_pretty` + `fs::write` 明文写 `~/.z-biz-tool-aigen/config.json`（第 57-64 行），无加密、无权限位设置、非原子写。
- **A3 API Key 全量回传前端**：[`load_api_config`](../../src-tauri/src/commands.rs) 返回含 `api_key` 的整个 `ApiConfig`（第 98-109 行）；前端存入 Zustand（[`aiStore.ts`](../../src/stores/aiStore.ts) 第 46-58 行）与 React state（[`App.tsx`](../../src/App.tsx) 第 32/42 行）。密钥进入渲染进程可读内存。
- **A4 CSP 关闭**：[`tauri.conf.json`](../../src-tauri/tauri.conf.json) `security.csp = null`（第 23 行）。配合 A3，任何注入脚本即可读取密钥。
- **A5 权限面偏宽**：[`capabilities/default.json`](../../src-tauri/capabilities/default.json) 同时开启 `fs:default` 与 `shell:default`（第 10-11 行）。当前业务代码未见前端直接调用 fs/shell 插件（图片下载走 `<a download>`、复制走 `navigator.clipboard`），属未收敛的多余能力。

### B 类：功能正确性
- **B1 图片 model/size 参数被静默丢弃**：前端 [`ImageGenPanel.tsx`](../../src/components/ImageGenPanel.tsx) 生成时传 `{prompt,count,model,size}`（第 46 行），但命令 [`generate_image`](../../src-tauri/src/commands.rs) 只签名 `prompt,count`（第 6-10 行），[`generate_image_api`](../../src-tauri/src/ai_client.rs) 请求体硬编码 `"size":"1024x1024"` 且不含 model（第 87-91 行）。→ 用户的模型/尺寸选择 100% 无效。
- **B2 视频生成返回占位符**：[`generate_video_api`](../../src-tauri/src/ai_client.rs) 异步任务分支直接 `return Ok(format!("task:{}", task_id))`（第 232-236 行），无轮询；前端 [`VideoGenPanel.tsx`](../../src/components/VideoGenPanel.tsx) 把 result 直接塞进 `<video src={result}>`（第 44 行）→ 得到 `task:xxx` 无法播放。README 亦标注视频"功能开发中"（[`README.md`](../../README.md) 第 8 行）。
- **B3 PPT 产物是临时 HTML 而非可交付文件**：[`generate_ppt_file`](../../src-tauri/src/ai_client.rs) 写 `std::env::temp_dir()/z-biz-tool-aigen/*.html`（第 312-321 行），前端用 `<Button href={result}>`（[`PptGenPanel.tsx`](../../src/components/PptGenPanel.tsx) 第 57 行）指向本地绝对路径，webview 中大概率无法下载/打开；临时目录会被系统清理。
- **B4 模型清单与单一 base_url 冲突**：[`TextGenPanel.tsx`](../../src/components/TextGenPanel.tsx) 模型下拉混列 `gpt-4o`/`gpt-4o-mini`（OpenAI）与 `abab6.5s-chat`（MiniMax）（第 25-30 行），但全局只有一个 `base_url`（默认 `https://api.minimax.chat/v1`，[`ai_client.rs`](../../src-tauri/src/ai_client.rs) 第 17 行）。选 OpenAI 模型打 MiniMax 端点必然失败。
- **B5 历史时间戳是裸秒字符串**：[`now_str`](../../src-tauri/src/commands.rs) 返回 `SystemTime` 秒数的字符串（第 127-134 行），非 ISO/本地时间，直接展示不可读。
- **B6 图片历史结果用 `", "` 拼接且可能是 base64**：[`generate_image`](../../src-tauri/src/commands.rs) `result: urls.join(", ")`（第 24 行），而 `generate_image_api` 对 `b64_json` 会返回 `data:image/png;base64,...`（[`ai_client.rs`](../../src-tauri/src/ai_client.rs) 第 119-120 行）→ 历史记录可能塞入超长 base64，且逗号拼接无法可靠还原多结果。

### C 类：可靠性与状态
- **C1 历史仅内存、重启即失**：[`AppState.history`](../../src-tauri/src/ai_client.rs) 是 `Mutex<Vec<HistoryItem>>`（第 36 行），`generate_*` 只 `insert`+`truncate(100)`（[`commands.rs`](../../src-tauri/src/commands.rs) 第 28-34 行等），从不落盘；`load_config` 持久化了配置但历史无任何持久化。
- **C2 无超时**：所有请求 `Client::new()`（[`ai_client.rs`](../../src-tauri/src/ai_client.rs) 第 85/139/189 行），未设 `timeout`/`connect_timeout`，网络异常时无限挂起。
- **C3 无取消**：[`useGeneration`](../../src/_shared/useGeneration.ts) 无 AbortController/取消入口（第 17-28 行），Rust 侧命令也无 cancel token。
- **C4 无重试/降级**：请求失败即 `Err(String)` 冒泡，前端 `setError(String(e))`（[`useGeneration.ts`](../../src/_shared/useGeneration.ts) 第 23-24 行）直接展示原始错误串（可能含上游响应体）。
- **C5 历史 UI 缺失 + Store 双通道**：`loadHistory` 把数据写进 store，但 App/面板从不渲染 `history`（Grep 确认 `.history` 仅出现在 store 内部）；同时面板用 `useGeneration` 直接 `invoke`，绕过 store 的 `generateImage/generateText`（这两个方法因此为死路径）→ 存在两套并行、彼此不同步的生成/历史状态。
- **C6 面板切换丢失结果**：结果保存在各面板本地 `useGeneration` state，`Mode` 切换即卸载组件（[`App.tsx`](../../src/App.tsx) 第 91-94 行条件渲染），生成结果无法跨面板保留。

### D 类：工程化
- **D1 零测试**：全仓 Grep 无 `vitest/jest/*.test.*/*.spec.*`，Rust 无 `#[cfg(test)]`（0 匹配）。
- **D2 CI 无质量门禁**：[`build.yml`](../../.github/workflows/build.yml) 仅安装依赖 + `tauri build` + 上传产物（第 52-80 行），无 `typecheck`/`lint`/`test` 步骤，尽管 package.json 已有 `typecheck` 脚本（[`package.json`](../../package.json) 第 11 行）。
- **D3 reqwest 特性冗余/TLS 未显式**：[`Cargo.toml`](../../src-tauri/Cargo.toml) 引 `reqwest` 带 `multipart`（第 23 行）但源码未见 multipart 使用；未显式声明 TLS 后端。
