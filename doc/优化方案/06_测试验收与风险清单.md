## 6b. 原生壳 E2E 通道（2026-09-23 补）

WKWebView 没有可挂的 CDP，因此用"页内驱动 + stderr 回传"取原生壳内的实测数据：
`npm run tauri dev`（devUrl=vite）+ `public/e2e.js` 驱动 + 临时 `#[cfg(debug_assertions)] e2e_log` 命令把结果打到 stderr，
假上游用上面的 `tools/mock_provider.py`。**跑完必须还原**（删驱动、删 index.html 那行、删 `e2e_log`、重刷 dist、grep 确认零残留）。
已由此抓到并修掉：`SubmitAck` 少 `rename_all="camelCase"` → 前端读到 `requestId=undefined` → 任务事件全丢（vitest 因两侧各写各的假形状而没抓到）。
两个环境坑：**5173 被并行会话的 vite 占用**（不能杀别人的端口，故 runner 自己挑空闲端口并用 `TAURI_CONFIG` 覆盖 devUrl）；
**本机挂了 HTTP 代理**，`urllib` 对 localhost 的探测会变成超时/502，必须 `ProxyHandler({})` 显式绕过。
另一个"失败即证据"：E2E 把数据目录隔离到 `/tmp` 时 `assetRender=blocked-or-error` ——
这正是 `assetProtocol.scope`（只允许 `$HOME/.z-biz-tool-aigen/results/**`）在挡越界读取；默认目录里同一驱动跑到的是 `loaded 1x1`。
